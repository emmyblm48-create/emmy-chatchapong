จัดการกิจกรรมโหวต

สร้างกิจกรรมโหวตใหม่ เลือกโหมด Token และเปิด/ปิดโหวตของแต่ละกิจกรรม Major Vote

ประวัติการเข้าหน้านี้ใครเข้ามาเมื่อไหร่ และการใส่ PIN ผิด
Burned — Token ที่ใช้โหวตถูกหักถาวร ไม่ได้คืน
Locked — Token ถูกล็อกไว้ ได้คืนครบ 100% เมื่อปิดโหวต
Partially Burned — ได้คืนบางส่วนตาม % ที่กำหนด เมื่อปิดโหวต
ระบบคืน Token อัตโนมัติทันทีที่เปลี่ยนสถานะเป็น Closed · คะแนนโหวตของเมมเบอร์ไม่ลดลง · คนที่โหวตไปแล้วได้คืนตามโหมดตอนที่โหวต
